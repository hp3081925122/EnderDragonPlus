# 龙之研究龙蛋兼容性测试

测试日期：2026-10-16。

## 环境

- Minecraft 1.20.1，Forge 47.4.23，Java 17。
- Ender Dragon Plus 0.0.1，当前项目源码及 Mixin。
- Draconic Evolution 3.1.2.621，CurseForge 文件 6793843。
- Brandons Core 3.2.1.302，文件 5422013。
- CodeChicken Lib 4.4.0.509，文件 5292543。
- 三个第三方模组仅作为 Gradle runtimeOnly 开发运行依赖，未加入 mods.toml，也不打包进本模组。

## 方法和边界

使用真实 Forge 专用服务端和全新临时世界，加载四个实际模组。临时验证类通过 Forge 事件总线记录 LivingDeathEvent、LivingDropsEvent，以及实体类型、龙战管理器和实际龙蛋方块。

测试程序由服务端启动事件执行：首次使用原版龙战管理器创建末影龙；后续在祭坛放置四颗水晶，调用 tryRespawn，逐 tick 执行全部原版复活动画（604 tick），不跳过复活动画阶段。终焉水晶通过与物品放置相同的持久数据标记激活增强龙。使用 Forge FakePlayer 的玩家攻击伤害命中龙头，再逐 tick 执行实体完整死亡过程，直至移除。并非真人客户端手工战斗，也未覆盖其他整合包模组。

为了分别验证配置两种取值，测试过程中直接切换 DEConfig.dragonEggSpawnOverride 的运行时布尔值；服务端生成的配置默认也是 true。/kill 对照直接执行命令最终调用的 EnderDragon.kill()。

完整程序、初始化脚本、隔离世界和启动日志均位于 D:/AI临时文件/edp-de-compat-20261016。下载依赖时 Gradle 经代理出现 TLS 握手失败，改用同坐标、相同发布 JAR 的临时本地 Maven 仓库完成运行；没有改动生产 Java 源码或死亡流程。

## 实际结果

| 测试项 | 配置 | 死亡掉落事件次数 | 龙蛋方块 | 结论 |
|---|---|---:|---|---|
| 首次击杀 | true | 1 | (0, 68, 0) | 原版首杀蛋正常 |
| 普通水晶完整复活后正常击杀 | true | 1 | (0, 68, -4) | DE 补蛋正常 |
| 终焉水晶完整复活的增强龙正常击杀 | true | 1 | (0, 68, -4) | DE 补蛋正常 |
| 终焉水晶完整复活的增强龙正常击杀 | false | 1 | 无 | 配置关闭对照正常 |
| 终焉水晶完整复活的增强龙执行 /kill 路径 | true | 0 | 无 | 原版 kill 路径绕过死亡掉落事件 |

以上各项均保持 minecraft:ender_dragon 实体类型，龙战管理器正常。所有断言通过，SUMMARY failures=0；runServer 正常退出并显示 BUILD SUCCESSFUL。

结论：此精确版本组合未复现正常击杀的龙蛋兼容问题。实体 ID 未变，现有 Mixin 没有阻断被测正常死亡掉落路径。/kill 不触发 DE 所依赖的事件，无法用其验证正常击杀掉落；此结果不能证明玩家反馈一定使用了 /kill。

复活后的龙蛋由 DE 放在出口祭坛北侧 4 格处，而非首次原版蛋的中央位置。玩家若仍有问题，应核对具体 DE 版本、击杀方式、是否查看了该位置，以及其余模组是否干预死亡事件。
