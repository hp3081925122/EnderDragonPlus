# 2026-10-17 性能优化迁移

源版本：1.20.1 Forge。目标：1.21.1 NeoForge、26.1.2 NeoForge。

## 范围

迁移已完成的缓存/缓冲区复用、同帧地形采样与吐息射线复用、触发时间索引、大型特效细分与重叠层优化、保守视锥剔除。保留 optimizeHeavyEffects 配置与关闭后原视觉路径。龙鳞弹幕的数量、轨迹、尾迹和命中效果保留。

移除临时 /edpdebug 命令、JFR/GPU/CSV 采样、调试网络负载、调试提示和常规技能调试日志。已有采样文件保留用于追溯，不删除用户采样目录。

本轮不包含尚未实现的噪声纹理离线生成、本体染色渲染重构。

## API 适配

- 1.21.1 保留 MeshData/BufferUploader 与当前渲染事件矩阵、DeltaTracker 用法。
- 26.1.2 保留当前 GPU 管线 EdpGpu、CameraRenderState、AfterLevel 事件、目标版本粒子/世界 API。
- 不将 1.20.1 GL 状态或网络实现直接覆盖高版本。
- 剔除只影响世界绘制，不影响生命周期、子效果、碰撞伤害、预警/安全区与屏幕反馈。
- 资源注册 ID、数据包目录及 pack.mcmeta 保持各目标版本已有格式；本轮不迁移玩法/配方资源。

## 验证计划

逐版本 build、扫描调试残留、检查 JAR 临时类、核对优化实现与视觉参数。按项目现有设施验证专用服务端启动与所有技能，记录实际通过范围；客户端视觉需要目标版本游戏实测，不以 build 或服务端测试代替视觉验收。

## 状态

迁移与清理已完成。

- 三个版本均移除临时调试命令、网络调试类型、性能采样及普通技能日志，保留错误与警告。用户已有采样目录未删除。
- 12 个 VFX 类迁移完整：1.21.1 正文与源版一致；26.1.2 仅 ClipContext、NBT 与世界高度 API 有差异。
- 几何缓存、地形采样、工作数组、同帧吐息射线与触发时间索引完整迁移；提交绘制和 GPU 管线仍按目标版本实现。

- 源码扫描无 DebugProfiler / DragonDebug / DEBUG_PROFILE / edpdebug / DEBUG_LOGGING 残留，无普通 info/debug/trace 日志调用。资源 JSON 均解析通过。

## 服务端验证

两个高版本分别使用当前项目 NeoForge/JDK，在 `D:/AI临时文件/edp-opt-migration-20261017/server-1211` 与 `server-2612` 创建隔离专用服务端。临时源目录通过 Gradle init 替换，不进入生产源码。

每版 70 条通过记录：12 个技能与转阶段护盾逐项推进至结束，验证特效消息产生；检查阶段状态、首次命中查询与完整查询顺序一致、miss 后复用列表清空、基础攻击力乘倍率、满击退抗性、优化弹幕首次命中伤害及命中后终止。测试夹具禁止自然连招干扰，技能结束后继续推进 160 次逻辑以覆盖残留危险区域。

这些是专用服务端中手动推进技能逻辑的功能检查，不是客户端帧率、自然 AI 长期战斗或画面一致性验收。部分技能的测试站位未命中实体，不据阶段完成断言其所有伤害几何已穷尽测试；伤害通用路径及本轮改变的弹幕首次命中路径另有实际伤害断言。

临时验证类随后通过正式 clean build 清除，并对成品 JAR 扫描，禁止包含任何测试夹具或已删除的调试类。
