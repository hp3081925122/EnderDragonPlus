## 调试器修复

原实现同时 `setDestination`、`stop`、`dump`，带目标文件的录制在 stop 时写出并关闭，随后重复 dump 报 closed 并将目标文件截断。用户日志确认该异常，旧 client.jfr 为 0 字节。改成无预设目标录制、stop 后仅 dump 一次，并单独记录 `client-jfr-status.txt`；JFR 失败不影响 CSV 保存提示。

最小复现程序在 Java 17.0.18 和用户同款 Java 21.0.10 均复现旧问题，修复后的文件均能通过 RecordingFile 读取事件。由于原录制为空，此次尚无法通过调用栈认定 GC、驱动等待或某个其他模组是停顿根因。

## 本轮改动

客户端配置 `config/enderdragonplus-client.toml` 的 `[vfx] optimizeHeavyEffects` 默认 true，false 恢复本轮调整前的特效。切换后重启客户端，再运行同一调试指令进行对比。

- 大型冲击波：减少约四分之一环/柱细分，去除重叠的小内环；球形冲击波降低球壳细分。半径不超过 2.5 的冲击波全部豁免，保留龙鳞弹幕实体命中和方块命中效果。
- 新星：减少球壳和环细分，保留主爆炸球壳，去除重叠的内球壳。
- 黑洞、陨星、下砸：降低球体、圆环或柱体细分。陨星外围柔光直径 6 改为 5，核心和尾迹保留。
- 残留地面印记：焦痕本体保留，附加辉光在生命周期 35%–50% 渐隐，后半程不再提交辉光层。裂纹层保留。
- 完全在视锥外的大型冲击波和地面印记不提交绘制。使用包含整个效果的保守包围盒，地面印记包含维度完整高度。生命周期、子效果触发与屏幕反馈继续更新。并未实现所有特效的剔除，也未实现墙后遮挡剔除。
- 全部扭曲实例都不可见时，可跳过对应世界画面复制；独立的全屏反馈仍保持。
- 预警圈、安全区、技能数量、范围、时机和伤害参数保留。BarrageVfx 无改动。
- 调试 CSV 增加 instances / culled_instances，可测量实际剔除数量；环境文件记录优化开关。

纯几何数量：无球壳的大冲击波主体由 832 顶点降至 480，约减少 42.3%；这是顶点数量，不是帧率提升承诺。球体两个方向均降低约四分之一细分时，网格约减少 44%。实际整包提升待用户测试。
